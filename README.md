# Soso.Net

> 🚧 **Warning** Proceed at your own risk. This is an internal tool and it is being actively developed so it will change _a lot_. I'll try to keep the main branch stable, but expect many breaking changes without warning.

## Installation
Install via UPM by going to 'Package Manager' -> '+' -> 'Add package from git URL...' from the Unity Editor

Note: use '?path=package'

Example: 'https://github.com/mkyprice/Soso.Net.git?path=package'
